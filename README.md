
# Java File Watcher

## Description
A Java application that monitors a directory for file creation, modification, and deletion events using WatchService.

## Features
- Monitors a selected directory.
- Detects file creation events.
- Detects file modification events.
- Detects file deletion events.
- Handles overflow events.
- Handles interruption and shutdown.

## Technologies Used
- Java
- Eclipse IDE
- Java NIO WatchService

## How to Run
1. Open the project in Eclipse.
2. Open Main.java.
3. Right-click and select Run As → Java Application.
4. Create, modify, or delete files in the monitored folder.
5. Check the Console for detected events.
